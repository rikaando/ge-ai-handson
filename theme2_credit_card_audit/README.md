# サブテーマ 2: クレジットカード番号の検出

`data/ai_audit_logs.csv` の `prompt_text` に誤って入力された 14 桁・16 桁のクレジットカード番号をルールベースで検出し、`data/users.csv` と結合して発生部署や対象ログを標準出力に表示する Python ツールを Antigravity で作成します。

## データ仕様

`ai_audit_logs.csv` の `prompt_text` を調べ、`user_id` で `users.csv` と結合して部署名と氏名を特定します。

### `data/ai_audit_logs.csv`

監査対象の生成 AI 利用ログ 100 件です。`prompt_text` には架空のテスト用カード番号が複数件含まれています。

| カラム名 | 型 | 内容 |
| :--- | :--- | :--- |
| `event_timestamp` | 日時文字列 | イベント発生日時 (UTC) |
| `log_id` | 文字列 | ログ ID。`LOG-202610-001` 〜 `LOG-202610-100` |
| `trace_id` | 文字列 | 32 桁 16 進数のトレース ID |
| `user_id` | 文字列 | 実行ユーザーの ID |
| `tool_surface` | 文字列 | 利用機能 |
| `model_name` | 文字列 | 利用モデル |
| `input_tokens` | 整数 | 入力トークン数 |
| `output_tokens` | 整数 | 出力トークン数 |
| `latency_ms` | 整数 | 応答時間 (ミリ秒) |
| `prompt_text` | 文字列 | 判定対象のプロンプト本文 |
| `connector_name` | 文字列 | 呼び出したコネクタ・ツール名 |
| `response_text` | 文字列 | モデルの応答テキスト |

### `data/users.csv`

ユーザーマスタ 25 件です。`user_id`、`user_email`、`user_name`、`department`、`job_role` の 5 カラムで構成されています。

## 検出ルール

### 検出対象の形式

- 16 桁のカード番号: 連続した 16 桁の数字、ハイフン区切り `4桁-4桁-4桁-4桁`、空白区切り `4桁 4桁 4桁 4桁`
- 14 桁のカード番号: 連続した 14 桁の数字、ハイフン区切り `4桁-6桁-4桁`、空白区切り `4桁 6桁 4桁`
- チェックディジット条件: Luhn アルゴリズムを満たす番号のみを対象とし、偶然桁数が一致しただけの数字列を除外

### 検出対象から除外するデータ

ログ内には通常の業務番号も含まれています。前後の文字境界 (`(?<![0-9A-Za-z_-])` と `(?![0-9A-Za-z_-])`) を判定し、以下の数値を誤検知しないように実装します。

- 10 桁の注文番号 `ORD-2026101501`、12 桁の伝票番号 `202610180045`
- 13 桁の法人番号 `1010401089234`
- 15 桁のバッチジョブ ID `202610201530991`
- 18 桁のリクエスト追跡番号 `990011223344556677`
- 電話番号 `03-5555-0199`、日付付き文書番号 `2026-10-22-0930`、`trace_id`

## プロンプト例

続けて `agy` に以下を入力し、スクリプトと単体テストの作成・実行を指示します。

```text
theme2_credit_card_audit/README.md を読んで、data/ai_audit_logs.csv の prompt_text から 14桁および16桁のクレジットカード番号混入をルールベースとLuhn検証で検出し、data/users.csv と結合して検出件数・部署別内訳・該当ログ一覧を標準出力に表示する theme2_credit_card_audit/credit_card_audit.py と単体テストを作成してください (Web画面は作らず、コマンドライン実行のみにしてください)。13桁・15桁・18桁の業務番号を誤検知しないように境界判定を入れ、出力時は検出番号だけでなく prompt_text 本文中のカード番号も末尾4桁以外をマスクして生番号が出ないようにしてください。作成後は単体テストとスクリプトを実行して標準出力の結果を表示してください。
```

## 拡張アイデア

ベース実装が動いたら、グループで相談して CLI オプションや集計機能を追加します。

| 切り口 | 内容例 |
| :--- | :--- |
| 任意テキストの即時判定 (`--text`) | コマンドライン引数で渡した文章に 14 桁・16 桁のカード番号が含まれていないかその場で判定して標準出力に表示する |
| 国際ブランド (BIN) の判定 | 先頭桁のプレフィックス規則から `Visa`、`Mastercard`、`JCB`、`Diners Club` などの国際ブランドを判定して併記する |
| エージェント連携用の JSON 出力 (`--json`) | Gemini Enterprise や他システムからプログラム連携しやすいよう、構造化された JSON で出力するモードを追加する |
| Luhn 検証の有無による比較 (`--no-luhn`) | 桁数・境界ルールのみの判定と Luhn アルゴリズム併用時の検出差を比較できるようにする |
| 利用機能・時間帯別の集計 | どの部署や利用機能 (`tool_surface`) でカード番号の混入が起きているかを集計表示する |
