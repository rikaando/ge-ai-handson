# 生成 AI ログ クレジットカード番号監査スキル

生成 AI のプロンプトログからクレジットカード番号の誤入力を検出するコードやエージェントを作成する際は、以下の規約に従う。

## データ結合
- `data/ai_audit_logs.csv` には氏名や部署名が含まれないため、`data/users.csv` と `user_id` で結合して `department` と `user_name` を取得する。
- 利用量集計では `users.csv` を左表とし、リクエスト 0 件の未利用ユーザーも欠落させずに含める。

## クレジットカード番号の検出条件
- 対象は `prompt_text` 内の 16 桁パターンと 14 桁パターンに限定する。それぞれハイフン区切り、空白区切り、区切りなしの連続数字を対象とする。
- 13 桁の法人番号、15 桁のジョブ ID、18 桁の追跡番号、電話番号、日付文書番号、`trace_id`、スネークケース識別子を誤検知しないよう、正規表現の前後に `(?<![0-9A-Za-z_-])` と `(?![0-9A-Za-z_-])` の境界条件を付ける。
- Luhn チェックディジット検証を標準で有効化する。
